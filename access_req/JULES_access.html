Requesting access to the JULES code

In December 2025 the first release of the Simulation Systems including JULES repository on GitHub was announced. A GitHub account will be required for new developments.

The JULES GitHub repository is currently private (vn8.0 & vn8.1) with access to registered users. It will become a public repository with the next JULES release in mid-July (vn8.2), allowing anyone to contribute.

As we make this transition we are suspending new access requests.

Please note that while a GitHub account is required to contribute to a repository, it is not necessary to access a public one.

Thank you for your interest in JULES and your understanding.
