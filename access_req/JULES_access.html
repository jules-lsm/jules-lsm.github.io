Requesting access to the JULES code

We are pleased to announce the first release of the Simulation Systems including JULES repository on GitHub. A GitHub account will be required for new developments.

The JULES GitHub repository will be transitioning from a private to a public repository with the next JULES release in mid-July.

As we make this transition we are suspending new access requests. New JULES access will be available again from the next release with a GitHub account.
